# 校赛自测与验收

仅使用自制《朵朵找月亮》、自编问题及成人录音或合成音频。没有企业官方绘本、音频集、金标准或评测接口。自测只反映当前样本和设备。

## 运行步骤

1. 按《同学运行说明》冷启动，检查首页、书架、录音权限、播放和网络异常时的预览入口。
2. 用自制素材生成视频，记录模型、运行 ID、生成配置以及降级情况。
3. 运行 python scripts/index_video.py demo_book。按页与画面变化抽帧，用已配置的 VLM 生成描述及物体框，以模板匹配追踪短距离位移。配置 OpenAI 兼容的完整 embedding URL（PBSC_EMBEDDINGS_URL）、模型（PBSC_EMBEDDINGS_MODEL）和环境密钥（PBSC_EMBEDDINGS_KEY）可建立语义索引。遮挡和场景切换需人工抽查。重新合成后重建。
4. 运行 python scripts/review_book.py demo_book screen 初筛旁白和视频抽帧。指定复核人检查完整成片及音轨，执行 python scripts/review_book.py demo_book approve --reviewer 姓名 --ages 6-8 --notes "逐页完整复核结果"。不通过用 reject。审核记录绑定生成内容哈希，改生成内容后需重审。发布限制可通过 PBSC_CHILD_REVIEW=1 启用，一键启动默认启用。
5. 运行 powershell -ExecutionPolicy Bypass -File eval/make_test_audio.ps1。需要普通话桌面语音，也可请成人在本机录制 q01.wav 至 q30.wav。运行 python eval/run_school_eval.py --audio-dir eval/audio --label 校赛本机 --out data/school-eval/baseline.json。答案与依据分开判分，关键词初判需人工复核。按需要省略 --audio-dir 跑文本组。浏览器状态首响、首次音频可播放与 HTTP 完整返回分别记录。
6. 关掉常驻服务后，运行 powershell -ExecutionPolicy Bypass -File eval/compare_cpu.ps1，比对两款模型的正确率、响应 P95 和模型进程峰值工作集。评测报告保存在 data/school-eval/。

## 五分钟演示脚本

- 0:00–0:45 展示自制绘本原图、原文和翻页。
- 0:45–1:45 展示真实转写、问答和依据跳转。
- 1:45–2:50 播放已复核的视频，展示按秒定位与物体点击。
- 2:50–3:40 讲解 OCR、VLM、视频生成和审核的可追溯流程。
- 3:40–4:40 展示自测报告、失败样例和硬件条件。
- 4:40–5:00 说明限制和备用演示。故障时用明确标注的预置视频或截图。

## 说明书初稿与补证清单

项目将自制绘本转为可检索图文与互动视频。Flask 托管阅读器及业务 API，页面 OCR 与 VLM 提供可检索内容，本地 Qwen 和引用校验产出有依据的回答。关键帧索引负责视频跳转与坐标命中，模型筛查提供复核线索，人工决策负责成片放行。

补齐现场硬件、冷启动、网络故障恢复、录音权限、视频播放、VLM/配音实测、复核责任人与材料授权记录。备用截图建议保留首页、依据回答、视频触控和评测摘要；提交格式随校方要求确认。平板和云端属于待设备到位后的验收。

## 本机验证入口

- 备用截图保存在 data/school-eval/screenshots/。来自 Edge 桌面预览，包含首页和已打开的阅读器。预览视频资源经 HTTP 实测可下载。
- Windows 普通话合成测试音频保存在 eval/audio/。合成音频用于功能基线，真实说话人的口音和现场噪音仍待测试。
- VLM 限流时可用 --page 逐页补索引。成功页会缓存，本次已完成的帧会保留。用 --force 强制重建。

## 本机自测结果

2026-11-15 使用本机 CPU、同一册自制绘本、30 道文本和同题 30 条普通话合成录音。两组各完成 60 次请求，均无请求错误。正确率是关键词初判，仍需人工复核。P95 为完整 HTTP 响应耗时，工作集仅计 llama-server 进程。

| 模型 | 文字正确率 | 语音正确率 | 文字 P95 | 语音 P95 | 峰值工作集 | 审核拦截 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Qwen3 0.6B | 16.7% | 16.7% | 12.66 秒 | 15.75 秒 | 2184.4 MiB | 43/60 |
| Qwen3 4B | 93.3% | 93.3% | 17.56 秒 | 16.95 秒 | 4254.1 MiB | 1/60 |

校赛主演示采用标准 4B 配置。上述轮次是同题、同机的初测，期间审核输入细化为同时检查引用，报告不作严格单变量比较。该轮关闭了回答语音合成，视频仍在人工待复核状态，无法用这些数据评价可播放音频首响或完整的帧证据覆盖。查看 data/school-eval/lite.json 和 standard.json 获取逐题结果。

自制视频首段真实 VLM 保留 5 帧及物体框，随后返回 HTTP 429。结果保存在 data/school-eval/vlm-page1.json。其余帧、真实 embedding 服务、真人授权的 CosyVoice 复刻与正式人工签核仍待验收。
