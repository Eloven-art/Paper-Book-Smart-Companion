# 纸书智伴 · 冬日故事小屋

> 当前版本已接入根目录主后端。请在项目根目录执行 `.venv\Scripts\python -m server` 或双击 `启动项目.bat`，访问 http://127.0.0.1:8000/ 。选书、上传、生成、阅读和页面触控走 `/api/v1`；QA/ASR/历史等智能能力尚待实现。音色模块通过可选 `PBSC_VOICE_SERVICE_URL` 同源接入，详细启动方式及项目缺口以 `../docs/框架联调与项目缺口.md` 为准。以下内容保留为前端独立快照说明，其中静态启动、下载源码和主业务全为 mock 的描述不再适用于统一入口。

## 查看与启动
- 在线私有预览：保留原站点，在小屋页面底部下载完整源码。
- 静态演示：Python 3 环境下双击“启动网站.bat”，浏览器打开 http://localhost:8000。
- **使用音色克隆：先阅读“音色模块说明.md”，安装 requirements.txt 和 FFmpeg，双击“启动音色服务.bat”。**不要用静态启动器代替音色后端。
- Windows 可解压到 D:\绘本比赛前端网站。云端环境不能直接写入用户 D 盘。

## 四个入口
- 兔子：绘本生成演示，表单校验、等待、生成中、失败、重试、取消、成功与阅读。
- 狐狸：本机书架保存、打开、移除，保留页码；不是云端存储。
- 熊熊：参考声音上传/录音、注册、音色列表、任意新文字合成与播放、选作阅读声音。后端提供 ElevenLabs 适配器；没有配置服务时明确不可用，绝不返回假音频或系统声音代替克隆。
- 猫头鹰：演示书的三道固定阅读小测验。

## 文件
- index.html / style.css / app.js：小屋与阅读交互。
- ui/voice-panel.js：小熊声音面板，录音关闭时释放麦克风。
- api/service.js：故事、书架和问答演示适配。
- api/voice.js：真实音色后端请求、二进制音频与播放控制。
- backend/server.py：FastAPI、SQLite、音频解码转码、克隆服务适配。
- backend/launch.py：本机启动，密钥隐藏输入，仅保存进程内。
- tests/test_voice.py：后端协议测试，使用替身服务，不是实际人声音色测试。
- assets/：原 HTML 提取素材，未重绘。
- originals/：用户提供的三个 HTML 原样备份，参考功能未全部迁移。
- 音色模块说明.md：音色接口、配置、边界、启动与验收。
- 接口与验收.md：原始比赛接口待确认清单（音色模块状态以新版说明为准）。

## 真实能力与限制
故事、视频、识物、问答仍为明确标记的演示。小熊提供真实服务接入代码，但没有用户密钥或授权样本，因此未调用付费模型、未验证音色相似度。在线预览为静态托管，不运行 Python 后端；需要本机启动，或后续部署同源后端，才能注册和合成。

角色为整张透明图片，缺少独立动作层，确认反馈只有短暂提亮，不将整体摇摆冒充翻书或喝茶。支持减少动态设置。

已通过脚本语法检查、七项后端测试和原有任务状态/书架检查。浏览器桌面手机布局、录音设备、真实服务及音频播放验收尚未完成。样本授权、内容审核、年龄适配与团队复核材料仍需补齐。未公开发布比赛样本。
