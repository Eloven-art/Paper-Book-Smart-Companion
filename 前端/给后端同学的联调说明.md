# 给后端同学：怎么接这份前端

这是当前小屋前端快照，页面未改。你的后端若已完成，不必替换成包里的 Python 后端；后者只是独立音色模块的可选实现。

## 先区分两件事
1. 模型/服务 API Key：只配置在你自己的后端环境变量中，不放前端 JS，不发给浏览器。
2. 浏览器调用的业务 API：需要与这个前端的请求路径、字段、返回结构对齐。后端配置好 Key，不等于小屋已经自动接通。

## 最省事的部署方式
由现有后端或 Nginx 同源托管 index.html、app.js、style.css、assets/、ui/、api/ 中的 JS 文件，并反向代理业务接口。同源可以避免大多数跨域和 HTTPS/HTTP 混用问题。
注意：/api/voice.js、/api/service.js 是前端静态模块文件，不应被全局 /api 反向代理或认证规则拦截。把这两个静态文件单独配置，或迁移静态目录后同步修改 import。

## 具体改哪里
- api/service.js：故事、问答、书架等目前是 mock/本机实现。把对应方法换成你已有后端请求，并将返回数据映射成前端使用的结构。不能只把 config.mode 改成 real：当前有保护性报错。
- app.js：startTask() 现在没有传递真实绘本、表单字段或音色 ID，需要补齐；阅读页现在使用固定背景和演示书结构，需要接入真实页面图像、视频和音频 URL。这部分实际联调尚未完成，不能声称只填 Key 就行。
- api/voice.js：小熊音色 API 统一在这里。现有后端若用另一套接口，就在这里转换请求字段与返回结果，不要改散各个页面。
- ui/voice-panel.js：小熊界面，保留当前版本。自定义文字用于开发试听，不是生成绘本的必填项。
- originals/tts_v2.html 和 voice_register.html：原始参考页面，保留完整原代码和已有 /tts-story-book/api 请求。用于对照真实接口，不能把这些路径认定为赛事统一评测接口。

## 小熊当前需要的接口
GET /api/voice/status → {configured:true, audio_tools:true}
GET /api/voices → {voices:[{id:"本地音色ID",name:"声音名",status:"ready"}], selected_voice_id:"本地音色ID"}
POST /api/voices → multipart：name、audio（文件）、consent=yes；返回 {voice:{id,name,status:"ready",duration:30}}
POST /api/voices/selection → JSON {voice_id:"本地音色ID"}；返回 {selected_voice_id:"本地音色ID",name:"声音名"}
POST /api/voices/{id}/speech → JSON {text:"需要朗读的绘本文字"}；成功直接返回 audio/mpeg 音频二进制。
错误统一 {error:{code:"错误码",message:"说明"}}，使用对应非 2xx HTTP 状态。

如果继续用现有 /enroll、/custom-voices、/tts，只需在 api/voice.js 映射。现有接口若返回音频 URL，要先获取并转换成可播放 Blob，或调整播放器适配；不能直接把 URL JSON 当音频。

## 音色如何进入真实绘本生成
1. 注册得到可复用的音色 ID，并在后端保存其与模型/服务音色标识的映射。
2. 用户在小熊选择音色；后端保存本次选择，或生成请求显式传递 voice_id。
3. 绘本生成后，将每页/每段真实故事文字交给 TTS，并使用同一音色 ID。
4. 返回可访问的音频/视频 URL、页序和任务状态，阅读页展示并播放。
用户不需要手动输入绘本文字；试听输入只用来测试。当前尚未打通真实故事视频流水线的这条链路。

## 可选：直接运行包里的独立音色后端
安装 Python、FFmpeg，项目目录执行：
  py -m pip install -r requirements.txt
然后双击“启动音色服务.bat”，隐藏输入 ElevenLabs Key；也可设置服务端环境变量 ELEVENLABS_API_KEY 后启动。
打开 http://localhost:8000。仅启动“启动网站.bat”是静态预览，没有音色后端。
如果你用的不是 ElevenLabs，替换 backend/server.py 的 provider，或者直接复用自己的后端；不需要为了这份前端更换模型。

## 联调验收顺序
先开一份真实绘本 → 生成任务真实状态与结果 → 播放音视频 → 同一音色朗读两段不同绘本文字 → 语音问答携带书籍/页面/视频时间上下文 → 点击识物坐标和对象结果 → 书架保存读取。
把你现有接口说明或成功请求/响应样例发回来，再逐个接适配器。主业务仍是 mock，音色仅已实现服务适配，真实模型效果未验证。
