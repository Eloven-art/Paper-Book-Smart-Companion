# 接口边界与验收

## 真实与演示
新版默认全部业务数据为 mock，本地书架和设备系统语音是本机真实能力，但不是后端服务。演示图片复用小屋背景，无生成视频；触控识物是固定按钮标注，不是视觉模型。语音提问尚未开启，不采集麦克风。文字问答只返回明确演示回执，不模拟真实答案。试题为固定原创题，非隐藏测试或模型输出。

## 参考源码已出现的请求（不是已确认的统一评测协议）
以下路径前缀 `/tts-story-book/api`，来自 originals，不代表当前服务可用。
- GET /bookshelf，POST /bookshelf、/bookshelf/load、/bookshelf/remove：书架保存、载入与移除，使用 session_dir。
- POST /create-session：创建目录，读取 success、session_dir。
- POST /generate-story-stream：JSON story_topic、main_role、scene、knowledge_points、lang、deep_think；fetch 流式读取 SSE。当前前端不解析此真实流。
- POST /generate-image：JSON prompt、index、story_title、main_role、scene、prev_image_path、session_dir。
- POST /generate-audio：JSON text、voice、index、session_dir。
- POST /generate-video：JSON prompt、image_path、session_dir、paragraph_index。
- POST /file-exists：JSON file_path，读取 exists；参考代码通过文件路径推测完成状态，需要确认任务 API。
- GET /custom-voices：读取 success、voices；参考代码还有 /api/custom-voices 回退路径。
- POST /enroll：multipart audio、text、spkname；页面读取 mos、wer，错误读取 message。
- POST /asr：multipart audio（WAV）；读取 success、text。
- POST /nlu：JSON question；读取 success、answer。需确认绘本、页面、视频时间和会话上下文如何传递。
- POST /tts：JSON text、voice，可传 session_dir；读取 success、audio_path。
- POST /analyze-image：图片分析；POST /analyze-video-frame：视频及时间点分析；完整字段须与后端代码核对。
- POST /generate-baike、/generate-exam、/save-exam-result：百科及小测验依赖，不是比赛核心必需项。

## 必须向后端确认
1. 原绘本选择/多图上传、页面顺序、OCR/VLM 结构结果、文件限制、Multipart 或对象存储上传方式。
2. 原绘本参考图如何进入生成链路，风格一致性与跨页上下文如何关联。
3. 任务 ID、真实阶段、进度、失败码、查询频率、超时、断线重连、重试幂等、服务端取消是否支持。
4. 音色列表的 ID/显示名/试听地址，音色注册音频格式与时长；合成地址、过期时间和跨域。
5. ASR 格式、录音时长；NLU 的绘本 ID/页面/视频时间/会话和图片语音历史字段；视频内容检索证据。
6. 图像与视频帧识别坐标系、边界框格式、缩放与留白映射，识别响应超时。
7. 书架存储期限、删除语义、会话隔离；音视频资源读取方式与权限。
8. 比赛统一输出与评测接口另行提供，PDF 没有具体路径或延迟数值。

request() 目前统一配置 30 秒超时，仅为框架默认值，不是赛事标准；视频异步任务必须单独按协议设置。真实模式有保护性报错，避免只改一个开关就误以为接通；在适配层完成协议后，再切换实现。模型密钥不得放入前端。

## 后续浏览器验收清单（尚未执行）
- 桌面 1440×900、手机 390×844 与 360×740：角色摆位、家具接触、文字、弹层滚动与无横向溢出。
- 四只角色鼠标/触摸/键盘打开，关闭按钮、外部点击、Esc 收起与焦点返回。
- 兔子空字段提示保留；模拟成功、失败、重试、取消；关闭任务后重开能看到状态。
- 阅读翻页、首尾禁用、保存后继续阅读；挑战答题解释与退出。
- 无中文系统语音、拒绝存储等异常；朗读切页停止，真实音频接入后检验播放失败恢复。
- 图片加载、网络请求、控制台；真实后端接通后测量端到端延迟，不用 mock 耗时代表成绩。

## 比赛边界
核心优先：原绘本理解、互动视频生成、语音问答、触控识别、多 Agent 真实编排。挑战可延后；音乐、弹幕、自由口述评分未新增。数据仅用于授权赛事范围，当前不公开发布用户样本。素材授权和来源清单、年龄适配、内容审核、复核责任及复现材料需团队补齐。
