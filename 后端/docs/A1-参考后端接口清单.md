对象：`../赛题内容/参考代码/story_tts_server.py`（Flask，2470 行）及其依赖模块。
实测数据：[A1-参考后端实测结果.md](A1-参考后端实测结果.md)，由 `scripts/smoke_reference_server.py` 自动生成，可随时重跑。
测试日期：2026-11-11，Windows 11，Python 3.13.9。

## 1. 结论

| 结论 | 数量 | 说明 |
|---|---|---|
| 已跑通 | 17 | 全部是不依赖外部服务的接口：页面托管、书架、会话目录、读文件、健康检查 |
| 依赖外部 API 待验证 | 17 | 故事、TTS、音效、音乐、配图、视频、图像识别、问答、ASR、声音注册 |

**“依赖外部 API 待验证”的 17 个接口本次没有做真实调用。** 原因是这台机器上没有任何外部服务的地址和密钥，`config.py` 里全部是占位符 `xxxx`。所以这些接口的真实可用性、单次耗时和费用目前都是未知的，表里记的耗时只是“请求在本机立刻失败”花的时间。拿到地址和密钥后，写进仓库根目录的 `.env`，重跑下面的命令，表格会自动更新成真实结果：

```bash
python scripts/smoke_reference_server.py
```

注意重跑会产生真实费用（尤其是配图和视频），建议先只配置一两个服务。

## 2. 启动方式与依赖

- 入口：`python story_tts_server.py`，监听 `0.0.0.0:5000`，端口和地址写死在代码里。
- 配置：`config.py` 从环境变量读取 11 组外部服务的地址、密钥、模型名，变量名见仓库根目录 `.env.example`。
- 生成结果写到 `TARGET_DIR`（默认就是代码所在目录）下的 `output_dir/`、`bookshelf/`、`prompt_dir/`。
- 依赖：`requirements.txt` 列出的包，另外 `opencv-python` 是必需的（截帧），`oss2` 是视频生成必需的（见 3.3）。

本仓库提供了一个不改动参考代码的启动脚本，顺带解决 3.1 和 3.2 两个问题：

```bash
python scripts/run_reference_server.py          # 然后打开 http://127.0.0.1:5000/tts-story-book/tts_v2.html
```

## 3. 实测发现的问题

以下每一条都是实际运行验证过的，不是只看代码的推测。

### 3.1 前端请求的地址后端没有注册（本机直接运行时页面功能全部不可用）

`tts_v2.html` 里所有请求都写成 `/tts-story-book/api/...`，后端只注册了 `/api/...`。带前缀的路由只有两个页面和 favicon。实测 `GET /tts-story-book/api/bookshelf` 返回 404。原环境应该是靠反向代理去掉前缀的。
处理：用 `scripts/run_reference_server.py` 启动，同一个应用同时挂在 `/` 和 `/tts-story-book` 下，实测两种地址都返回 200。

### 3.2 中文 Windows 上把输出重定向时，服务启动就崩溃

代码里有大量带表情符号的 `print`。直接在终端窗口里运行没问题；但只要把输出重定向到文件或管道（后台运行、写日志时都会这样），Python 的输出编码是 GBK，表情符号编码失败。实测：没装 `oss2` 时，`generate_video.py` 第 29 行的警告在导入阶段就抛 `UnicodeEncodeError`，服务起不来。
处理：启动前设置环境变量 `PYTHONUTF8=1`，或使用上面的启动脚本。

### 3.3 视频生成没有任务状态，失败时调用方不知道

- `/api/generate-video` 提交后立即返回“任务已提交”，没有任务号，也没有查询接口。前端靠反复调用 `/api/file-exists` 看 mp4 文件有没有出现来判断是否完成，失败和“还在生成”无法区分。
- 生成前必须先把图片上传到阿里云 OSS 拿公网地址（`upload_image_to_oss`），需要 `oss2` 库和 4 个 OSS 环境变量，上传路径前缀 `NLP/zouting1/huck-comp/` 写死在代码里。没有 OSS 时任务在后台静默结束。实测：未配置时接口照样返回 `success: true`。
- 同类的“失败但返回成功”还有两处：`/api/generate-music`（设计如此，为了不阻塞前端）和 `/api/asr`（实测 ASR 连不上时返回 `{"success": true, "text": ""}`）。

这是新后端要补“异步任务队列与状态查询”的直接原因。

### 3.4 可以读到服务目录以外的文件

- `/api/audio/`、`/api/image/`、`/api/video/` 把请求路径直接拼到 `TARGET_DIR` 后面，没有检查是否越界。实测 `GET /api/image/..%2Foutside.png` 成功返回了上级目录里的文件。
- `/api/file-exists` 接受绝对路径。实测传 `C:/Windows/win.ini` 返回 `exists: true`。
- `/api/analyze-image` 接受任意本机路径并把文件内容发给外部服务。

服务监听 `0.0.0.0` 且允许任意跨域，比赛现场同一网络里的其他人都能访问。新后端的文件接口做了越界检查（有测试覆盖）。参考后端如果要在现场使用，至少改成只监听 `127.0.0.1`。

### 3.5 其他缺陷

| 位置 | 现象 | 影响 |
|---|---|---|
| `text_agent_base.py` `Gemini3ProAgent.call` | 请求抛异常时，`except` 里引用了还没赋值的 `response`，实测报 `cannot access local variable 'response'` | 深度思考模式、百科、试卷在网络出错时直接 500，自带的 10 次重试不会生效 |
| `ai_story_generate.py` 第 177 行 | 重试时给 `call()` 传了它不接受的 `seed` 参数 | 分章生成第一次校验不过就会抛 `TypeError` |
| `story_tts_server.py` 第 460 行、`ai_story_generate.py` `parse_list` | 对模型输出直接 `eval()` | 模型输出被当作代码执行，应改为 `json.loads` 或 `ast.literal_eval` |
| `/api/asr` | 同一段音频先后连接两次 ASR 服务，第一次的结果被丢弃；并且假定 WAV 头固定 44 字节 | 语音识别耗时翻倍，直接影响交互延迟这一评分项（步骤 6、7 处理） |
| `/api/bookshelf/remove` | 用 `'/bookshelf/' in 路径` 判断是否删除目录，Windows 路径是反斜杠，判断不成立。实测移出书架后目录还在 | Windows 上磁盘只增不减；Linux 上正常 |
| `get_session_dir` | `exam_session_dir` 写成了 `"sfx"` | 试卷目录没有预先创建（生成试卷时会自己建，影响小） |
| `requirements.txt` | 固定了 `pydantic==2.5.0`，它依赖的 `pydantic-core 2.14.1` 没有 Python 3.13 的安装包，实测 pip 报找不到版本 | Python 3.13 上按原文件装不上；用 3.10/3.11 或放宽版本即可。本次实测用的是 pydantic 2.14 |
| `generate_image.py` | 单次请求超时 3000 秒，最多重试 6 次 | 服务异常时一个请求可能挂几个小时 |

## 4. 外部服务与计费口径

费用需要对照服务商的价目表填写，这里只列出各服务的计费单位，供预算时参考。本次没有产生任何费用。

| 服务 | 环境变量 | 默认模型 | 被哪些接口使用 | 计费单位（待核实） |
|---|---|---|---|---|
| 故事大模型 | `SIMPLE_STORY_WRITER_*` | deepseek-v3.2 | 故事、百科、试卷 | 输入/输出 token |
| NLU 问答模型 | `NLU_*` | qwen3-30b-a3b | `/api/nlu` | token |
| 图像理解 | `IMAGE_ANALYSIS_URL`、`IMAGE_*` | qwen3-vl-30b-a3b-instruct | 图片/视频帧识别 | token（含图片） |
| 文生图 | `TEXT2IMAGE_*` | gemini-3-pro-image | `/api/generate-image` | 张 |
| 图生视频 | `IMAGE2VIDEO_*` + OSS | doubao-seedance-1.0-lite-i2v | `/api/generate-video` | 视频秒数或次数 |
| 音效 / 音乐 | `TEXT2AUDIO_*` / `TEXT2MUSIC_*` | audio1.0 / imagination-bgm | 音效、背景音乐 | 次或秒 |
| TTS / 语音克隆 | `TTS_API_URL` / `VOICE_CLONE_TTS_API_URL` | v2_llm | 语音合成 | 字符数 |
| ASR | `ASR_WS_SERVER_URL` | — | `/api/asr` | 音频时长 |
| 声音注册 | `ENROLL_SERVER_URL` | — | `/api/enroll` | 次 |

这些服务里哪些是命题方提供、哪些要自己申请，需要向命题方确认；说明书第 4 章要逐项披露调用范围和额度。

## 5. 对新后端的取舍

- **沿用**：大模型、TTS、图生视频三类调用的协议形状（请求体、请求头、轮询状态码），环境变量名。
- **不沿用**：返回格式（没有统一外壳）、用目录路径当会话标识、同步阻塞的生成方式、文件接口。
- 参考后端保持原样留在 `../赛题内容/参考代码/`，新后端在 `server/` 和 `agents/` 里另写，互不影响。
