# 纸书智伴 · 同学运行说明

解压后运行下面几步，功能和原作者本机一致。整个流程只需一次配置。

## 0. 先确认电脑

- Windows 10/11 64 位
- Python 3.10–3.13（安装时勾选 **Add Python to PATH**）
- 16 GB 内存、至少 6 GB 空闲磁盘
- 有 NVIDIA 显卡最好（≥6 GB 显存）；没有也能跑，问答会慢一些

## 1. 解压并安装依赖

建议解压到**英文路径**（例如 `D:\pbsc`），中文路径也能跑。

```powershell
cd D:\pbsc\联调演示初版\前后端合并（初版）
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 2. 下载本地模型（约 2.6 GB，只需一次）

```powershell
.\.venv\Scripts\python.exe scripts\download_ocr_models.py
.\.venv\Scripts\python.exe scripts\download_asr_models.py
.\.venv\Scripts\python.exe scripts\download_llm_models.py
```

三个脚本默认走国内可达的 ModelScope / hf-mirror；下载失败会提示换源。
模型目录不入包，下载后放在 `data/models/` 下。

## 3. 配置文件

将项目目录中的 .env.example 复制为 .env，按需填入自己的 API Key。请将 .env 保存在本机。

没有 Key 时：本地 OCR、语音识别、Qwen3 问答仍可用；
CosyVoice 配音、图生视频、VLM 画面理解会降级或不可用。

## 4. 启动本地大模型（终端 1）

```powershell
cd D:\pbsc\联调演示初版\前后端合并（初版）
powershell -ExecutionPolicy Bypass -File scripts\start_llm.ps1
```

- 脚本会自动选第一块 NVIDIA 显卡；没有 NVIDIA 时加 `-Cpu`（速度明显变慢）。
- 看到 `listening on http://127.0.0.1:8080` 后，**另开一个终端**预热一次：

```powershell
cd D:\pbsc\联调演示初版\前后端合并（初版）
.\.venv\Scripts\python.exe scripts\warmup_llm.py
```

## 5. 启动网站（终端 2）

```powershell
cd D:\pbsc\联调演示初版\前后端合并（初版）
.\.venv\Scripts\python.exe -m server
```

浏览器打开 http://127.0.0.1:8000/ （也可以双击 `启动项目.bat`，它会自动装依赖并启动网站）。

## 6. 验证

- 首页应能看到自制绘本《朵朵找月亮》。
- 阅读页点“提问”，问“月亮掉到哪里去了？”应得到带页码依据的回答并朗读。
- 可选：`.\.venv\Scripts\python.exe -m pytest -q`，应为 116 项全部通过。

## 常见问题

| 现象 | 处理 |
|---|---|
| `SERVICE_NOT_CONFIGURED` | 终端 1 的模型服务没启动，先跑第 4 步 |
| 第一次问答很慢（10–20 秒） | 没预热，跑一次 `scripts\warmup_llm.py` |
| 端口 8000/8080 被占用 | 改 `.env` 的 `PBSC_PORT`，或关掉占用端口的程序 |
| 语音识别提示模型缺失 | 重跑 `scripts\download_asr_models.py` |
| 没有显卡、问答太慢 | 把 `.env` 的 `SIMPLE_STORY_WRITER_URL` 改成云端 OpenAI 兼容地址和 Key |
| 不想用原作者 Key | 换成自己的百炼 `DASHSCOPE_API_KEY` 和智谱 `VLM_API_KEY` |
