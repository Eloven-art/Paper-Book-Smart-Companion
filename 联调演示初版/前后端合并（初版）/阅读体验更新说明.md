# 本轮使用方式

1. 备份原项目，将本包覆盖到原来的「前后端合并（初版）」。保留原来的背景和四只动物素材。
2. 双击「启动项目.bat」。启动后使用 `http://127.0.0.1:8000/?preview=1` 检查前端；在线链接也使用同一套前端模式。
3. 在“大人准备绘本”选择一本完整 PDF，或一次选齐所有页面图片。书籍保存到这个浏览器的书架，下次从兔子或狐狸直接打开。
4. 阅读中用动物头像按钮听、看、问、找。所有互动都围绕当前这本书，不再为每个功能重新选图。

本包新增了兔子与猫头鹰透明素材、PDF.js 引擎、PDF 字体/CMap、整本本机书库；它们必须随本轮更新一起覆盖。前端字体为霞鹜文楷，原图内的字与水印不改动。

# 阅读体验更新版

1. 停止旧终端服务（Ctrl+C），先备份原项目。
2. 将本包的「前后端合并（初版）」放回原来同级位置，选择替换同名文件；这是原项目覆盖更新包，请保留原目录内的小屋 assets 素材，不要单独解压到空目录运行。
3. 双击「启动项目.bat」。它会创建虚拟环境、以 UTF-8 安装依赖、升级未被自行修改的自制示例并启动。
4. 出现 Running on http://127.0.0.1:8000 后，打开该网址并按 Ctrl+F5。

## 本次变更

- 新视频默认关闭烧录字幕，避免和原书文字叠加。保留原图中的原书文字，不自动擦除真实绘本上的文字。
- 右侧显示原文优先；改写旁白单独放在「听听故事里的另一种说法」中。旁白音频仍可能采用改写稿，并非逐字跟读。
- 本地随包加载「霞鹜文楷」，无需联网或安装系统字体；字体许可见 前端/assets/fonts/OFL.txt。
- 自制示例的三页绘本重新排印文字，并根据原几何图形的颜色标记生成可见物体轮廓。不是通用物体分割模型。
- 进入阅读页即提示可探索物体，提供柔和金色轮廓、点击讲解、键盘访问和提示开关；减少动态时保持静态提示。
- 其他绘本若只有 bbox，显示虚线区域提示；若提供 objects[].contours（原图像素坐标，多组多边形顶点），显示轮廓。没有标注就不显示。上传图片尚不具备自动分割能力。
- 视频缺少稳定追踪标注时不显示图片的静态轮廓，可切回图片探索。
- 技术状态折叠到「阅读说明」。

## 旧数据

启动脚本只更新图像哈希与原版或新版自制示例匹配的页面；自定义图像跳过。仅当三页均匹配且已有视频都是本地降级视频（或尚未生成）时，自动安装新版示例视频。
更新前的元数据、图片及已替换的音视频分别保存在 data/books/demo_book/ 下的 before-reader-update 备份中。
其他已有视频烧录的字幕不能通过网页隐藏，需要重新生成；生成缓存包含字幕开关，新配置会触发重新合成。
如需恢复视频字幕，在 .env 中设置 PBSC_VIDEO_SUBTITLES=1 后重启、生成视频。

## 边界

绘本图像内已有的文字属于图像内容，CSS 无法替换字体。本次只重绘自制示例的文字；真实绘本需保留原图，或经授权后另做文字分离与排版。
通用绘本的真实贴边轮廓依赖实例分割/人工标注，动画视频还需要物体跟踪；本次没有把矩形框包装成真实轮廓。
