# 整本阅读与动物小伙伴界面（本轮更新）

当前主界面已回到“书架 → 一本绘本 → 阅读中互动”。以下说明替代旧版首页并列功能入口的设计。

- 首页保留房间与四个角色。兔子默认续读最近一本；狐狸选择书架；小熊选声音；猫头鹰提供读后挑战。整本导入放在“大人准备绘本”。
- 兔子素材已移除蒲团，放回背景沙发；猫头鹰已移除小梯凳，落在背景已有的书架梯子上。移动端保持整个房间的坐标比例，并增加可点击的动物头像入口。
- 统一离线霞鹜文楷。主操作采用动物头像和圆润按钮；减少厚重方框与技术菜单。
- 阅读器只有一个主画面和一个视频播放器。提问、查找、记录在当前书旁边的抽屉展开，关闭后回到原画面，不换素材。
- “问一问”统一包含录音与文字；发送时关联当前书籍、页码、视频时间和最近选中的物体。继续播放会保留暂停位置。跨页则切换到对应的新页面。
- 前端试用支持一本 PDF 整体导入，或一次选择全部图片。原件通过 IndexedDB 保存在本机书架；阅读页数和模式记在本机。刷新后从兔子继续，不需要重新导入。
- PDF 只渲染当前阅读页。可提取 PDF 自带文字层及其坐标；扫描图片型 PDF 不冒充完成 OCR。其原图仍能正常阅读。
- 导入书籍的配套 PDF、TXT 和音频可保存到同一本书；在大人设置里查看、试听或作为提问音频使用。自制示例的附加素材仅保留在当前会话。
- 本地 OCR（RapidOCR）和本地语音识别（SenseVoice）已接入；VLM 适配层已接（`/vlm`，支持 OpenAI 兼容与 custom_json，等同学真实服务联调）；AI 视频可通过 `.env` 配置百炼 DashScope（`PBSC_I2V_PROVIDER=dashscope`），未配置时用本地推近片段。智能问答、真实讲述音色和物体分割仍等待 API；固定示例回答与占位素材保留明确说明，不代表完成真实推理。
- 默认本机根地址仍连接原后端。当前前端验收请使用 `http://127.0.0.1:8000/?preview=1`；在线版本默认使用前端模式。
- PDF 引擎使用本地 PDF.js 4.10.38 和同源 worker/字体/CMap；无需外链，许可见 vendor/PDFJS-LICENSE.txt 及 assets/pdf-resources 内许可文件。

本轮验证：整本图片原件持久化与重开；真实两页 PDF 的解析、文字层、原件保存与按页渲染；单阅读器的暂停上下文、问答/查找、录音释放、续读、配套音频重开。接口层与原 Flask 静态资源测试通过。

整合到当前系统后的补充验证：Python 111 项测试全部通过，前端 JS 7 项测试通过；用 Edge 无头浏览器截图检查了小屋首页、真实后端阅读页和 `?preview=1` 预览首页，动物头像按钮、霞鹜文楷、示例页轮廓素材和预览视频均能加载。真机触控、麦克风和完整 PDF 导入流程仍建议人工验收。

# 原版小屋前端补全与 API 对接

这次直接修改「前后端合并（初版）/前端」，保留房间素材和兔子、狐狸、小熊、猫头鹰四个角色。在线页与本机页使用同一套前端代码。默认本机连 Flask；`?preview=1` 是不依赖后端的前端试用。

## 入口与当前行为

| 入口 | 已完成的前端行为 | 仍依赖后端/API 的部分 |
|---|---|---|
| 绘本与导入 / 兔子 | 选书、图片上传、进度、停止、重试、完成后阅读 | 真实 OCR/ASR 已本地接入；VLM 画面理解、旁白和视频生成仍需外部服务（视频可接百炼） |
| 故事视频 | 整本/单页切换、播放、暂停、继续、结束、倍速、加载失败提示 | 新的视频素材、准确时间索引 |
| 语音提问 | 麦克风权限、开始/停止、60秒上限、试听、上传、移除、转写核对框 | ASR 转写；不会用固定文字假装识别音频 |
| 文字问答 | 提交、等待、停止等待、失败、回答、依据页跳转、视频时间跳转、回答朗读入口 | 真实问答、检索与回答 TTS |
| 原文与情节 | 原文匹配、已有情节字段匹配、翻页、右侧原文高亮、已有 OCR 行框高亮、视频跳转 | OCR 坐标、语义检索、视频对应关系；不是自由语义搜索 |
| 对话记录 | 本机保存文字、当前页面保留录音、回答与依据回看、读取会话、清空本机记录 | 服务端持久化；清空本机记录不删除服务端会话 |
| 页面素材 | 查看尺寸/标注/音视频状态；试用模式手工补原文与画面描述；本机 PDF/TXT 查看、音频试听及用于提问 | PDF 自动拆页、图片自动理解、测试录音自动识别 |
| 小熊 / 声音工坊 | 参考声音录音上传、授权、试听、音色选择、合成操作入口 | 保留原有独立音色服务；与孩子提问录音分开 |
| 狐狸 / 书架 | 保存书籍 ID 与阅读页、继续阅读、移除 | 当前为本机书架，不是多用户云书架 |
| 猫头鹰 / 阅读小挑战 | 自制朵朵示例的三道固定题；选项、反馈、结果、回到阅读 | 新绘本题库与验收判分 |

## 预演与真实模式

- 本机正常运行：`http://127.0.0.1:8000/`。请求原来的 `/api/v1` 与 `/api/voices`，不会自动退回假回答。
- 前端试用：`http://127.0.0.1:8000/?preview=1`。使用 `api/preview.js`，不需要服务商密钥。在线静态版将此模式设为默认。
- 假接口联调仍可用：`?mock=1`。与前端试用分开。
- 前端试用中的“预演生成流程”只展示提交、轮询、取消和完成入口；不生成新音频、视频或旁白，完成后仍阅读原素材。
- 朵朵示例提供少量固定问答，回答区始终显示“固定示例回答”；陌生问题没有预设答案会明确说明。
- 试用模式可真实录音和试听，但转写、音色克隆及回答朗读未接 API 时显示未接入，不产生假结果。
- 导入的新图片不自动套上朵朵的文字或轮廓。可手工录入文字/情节试查找；没有自动 OCR 或分割。导入素材刷新后需重新选择。
- 图片上的字体和水印不修改。前端字体为本地霞鹜文楷；正文与改写旁白分开。

## 接口与数据

统一请求由 `api/service.js` 管理；声音工坊仍走 `api/voice.js`。服务商密钥只能放在后端，不交给浏览器。

- `POST /api/v1/asr`：multipart 字段 `audio`；需要返回 `{text}`。前端先核对文字，再提交问答。该接口已接入本地 SenseVoice（`agents/asr_agent.py`，返回 `text/raw_text/language/emotion/event`，不调用外部 API）；`?preview=1` 的前端预演仍不调用真实识别。
- `POST /api/v1/qa/ask`：JSON `{book_id,page_no,question,play_time,session_id}`；需要 `answer_text,grounded,evidence,answer_audio_url,turn_id,created_at`。前端支持取消等待。
- `POST /api/v1/tts`：JSON `{text}`；需要 `audio_url`，若占位需标记 `is_placeholder`。
- `GET /api/v1/history?session_id=...`：需要 `turns[]`。记录中的依据结构与问答一致。
- 依据页：`{type:'page',page_no,quote}`；视频依据：`{type:'video',page_no,timestamp,time_range}`。视频 timestamp 为全书绝对秒数。
- 页面：`ocr_text.full_text,ocr_text.blocks[].{text,bbox},image_size,objects[].{name,bbox,contours,explanation},scene_summary,plot_events,time_range,video_meta`。
- `contours` 是原图像素坐标的多组多边形。只有 bbox 时显示虚线；有真实轮廓才沿轮廓提示。
- 当前图片高亮按文字行框显示，不声称具有字级定位。手工录入不产生图像坐标，只高亮右侧文本。
- 提问录音先送 ASR，再把核对的文字送 QA；录音与服务端对话的永久绑定还需 API 协议增加 audio_id 等字段。当前本机仅保留本次页面的录音供回听。

## 运行与更新

先停止旧服务并备份原目录，将更新包中的「前后端合并（初版）」覆盖到原同名目录，双击「启动项目.bat」。依赖安装使用 UTF-8，修复旧 Windows pip 读取中文注释时的 GBK 错误。

在线页底可下载本机更新包。为缩小下载包，省略了可选视频字幕用的 TTF 字体；前端所需 WOFF2 完整保留，已生成示例页不受影响。若将来启用烧录字幕，可通过 `PBSC_SUBTITLE_FONT` 指向本机中文字体。
