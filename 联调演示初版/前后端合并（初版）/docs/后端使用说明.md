# 后端使用说明

适用于 `server/`（服务）、`agents/`（生成节点）、`configs/`、`scripts/`。接口字段见 [接口约定_v0.1.md](接口约定_v0.1.md)。

## 1. 安装与启动

需要 Python 3.10 及以上（已在 3.13 上验证）。不需要另装 ffmpeg，MoviePy 自带。

```bash
python -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt
```

```bash
.venv\Scripts\python scripts\download_ocr_models.py
```

```bash
.venv\Scripts\python scripts\download_asr_models.py
```

```bash
.venv\Scripts\python -m server
```

第二、三步会下载 / 校验本地 OCR 模型（约 31 MB，`data/models/rapidocr/`）和 SenseVoice 语音识别模型（约 230 MB，`data/models/sensevoice/`）。当前交付文件夹里已带模型；模型不进 Git，新克隆或换机器时需要执行，否则 OCR 返回 503 `OCR_UNAVAILABLE`，ASR 返回 503 `ASR_UNAVAILABLE`。

Linux / macOS 把 `.venv\Scripts\` 换成 `.venv/bin/`。启动后：

- 真实接口 `http://127.0.0.1:8000/api/v1/health`
- 假接口 `http://127.0.0.1:8000/mock/api/v1/health`
- 如果仓库里有 `web/index.html`，根地址会托管前端页面

默认只监听本机。平板联调时用 `python -m server --host 0.0.0.0`，平板访问电脑的局域网地址。

单进程运行即可。任务队列在进程内，不要用多进程方式部署，否则各进程看不到彼此的任务。

## 2. 配置

把 `.env.example` 复制成 `.env` 再填写。`.env` 已被 git 忽略，密钥只放这里。

| 外部服务 | 变量 | 没配置时的降级方案 |
|---|---|---|
| 大模型（旁白 + 问答） | `SIMPLE_STORY_WRITER_URL` / `_API_KEY` / `_MODEL`；本地 Qwen3 默认 `http://127.0.0.1:8080/v1/chat/completions` | 旁白直接用原文；`/qa/ask` 返回 503 `SERVICE_NOT_CONFIGURED` |
| 语音合成（参考 HTTP） | `TTS_API_URL` | 占位提示音（时长按字数估算，每句开头一声轻响） |
| 语音合成（CosyVoice） | `PBSC_TTS_PROVIDER=cosyvoice`；`COSYVOICE_API_KEY` 或 `DASHSCOPE_API_KEY`；可选 `COSYVOICE_MODEL/VOICE` | 占位提示音，并在 `is_placeholder` / 运行记录里标明 |
| 图生视频（旧网关） | `IMAGE2VIDEO_URL` / `_API_KEY` / `_MODEL` | 静态页图缓慢推近 |
| 图生视频（百炼） | `PBSC_I2V_PROVIDER=dashscope` + `DASHSCOPE_API_KEY`，可选 `PBSC_DASHSCOPE_*` | 静态页图缓慢推近，并在 `video_meta.fallback_reason` 写明原因 |
| 本地 OCR | 不需要密钥；`PBSC_OCR_MODEL_DIR`、`PBSC_OCR_AUTO` 等 | 不降级：依赖或模型缺失时 OCR 接口返回 503 `OCR_UNAVAILABLE`，上传仍可完成 |
| 本地语音识别 | 不需要密钥；`PBSC_ASR_MODEL_DIR`、`PBSC_ASR_LANGUAGE` 等 | 不降级：依赖或模型缺失时 `/asr` 返回 503 `ASR_UNAVAILABLE` |
| VLM 内容理解 | `VLM_API_URL` / `VLM_API_KEY` / `VLM_MODEL`、`PBSC_VLM_PROTOCOL` | 不降级：未配置时 `/vlm` 返回 503；OCR 和阅读页仍可用 |

降级方案的作用是让整条链路在没有外部服务时也能跑通、能联调，**它们不是生成成果**。所有降级结果都会在分页数据、任务结果和运行记录里标明（`method`、`is_placeholder`、`is_fallback`、`fallback_reason`），`GET /api/v1/health` 的 `degraded` 字段会列出当前哪些服务在降级。演示和写说明书时请以这些标记为准，如实说明。

其余可调项（端口、上传大小、并发任务数、视频尺寸、转场时长、字幕字体等）见 `.env.example` 里的注释。

## 3. 通用功能

### 上传校验（`server/uploads.py`）
页面图片支持 png / jpg / webp / bmp，提问录音支持 wav / mp3 / webm / ogg / m4a。校验内容：扩展名白名单、文件头与扩展名是否一致、大小上限（默认 20 MB）、图片能否完整解码、像素总数上限、最小 64×64。文件名由服务端生成，不使用客户端传来的名字。上传整本书时任何一页不合格就整体拒绝，不会留下半本书。

### 本地 OCR（`agents/ocr_agent.py`、`third_party/RapidOCR/`）
上传绘本后默认自动提交整本 OCR 任务，也可以手动调用 `POST /api/v1/books/<book_id>/ocr`（可选 `page_no`、`force`）。识别在本地用 RapidOCR + ONNX Runtime CPU 完成，不调用外部服务、不产生费用。

- 源码：上游 `RapidOCR` 的 `python/rapidocr/` 包完整放在 `third_party/RapidOCR/`，未修改；`agents/ocr_agent.py` 通过 `sys.path` 引入。
- 模型：`data/models/rapidocr/` 下的 PP-OCRv6 det/rec small + PP-OCRv4 cls mobile，用 `scripts/download_ocr_models.py` 下载 / 校验。
- 输出：每页的 `ocr_text`（`full_text` + `blocks[].text/bbox/score`）和 `ocr_meta`（`run_id`、引擎、模型、置信度阈值、耗时）。`blocks` 按阅读顺序排列，`bbox` 是轴对齐的 `[x1,y1,x2,y2]`。
- 有 `ocr_meta.run_id` 的页面默认复用结果；`force: true` 才重新识别。原文变化会把 `safety_check.status` 重置为 `pending_review`。
- 只做文字识别。人物、物体、场景、情节仍需 VLM 节点；点击识物在页面还没有物体框时仍会返回 `hit=false`。
- 识别质量与纸质书的字体、反光、拍摄角度有关；本机在自制示例上 3 页约 10 秒（首轮含模型加载）。结果只作为旁白和检索的输入，**不能当作已人工复核的原文**。
- 假接口的上传任务用 `ingest` 模拟 OCR，不会真正识别图片。

### 本地语音识别（`agents/asr_agent.py`、`third_party/SenseVoice/`）
入口：`POST /api/v1/asr`，`multipart/form-data`，字段 `audio`；可选 `language`、`book_id`、`page_no`。识别是同步的，直接返回文本，不生成任务。

- 源码：SenseVoice 上游代码（MIT）放在 `third_party/SenseVoice/`；运行时使用同目录下 PyPI `funasr-onnx==0.4.11` 的完整源码（MIT），不需要 torch / funasr。
- 模型：`data/models/sensevoice/model_quant.onnx`（iic/SenseVoiceSmall 的 int8 ONNX 导出，Apache-2.0）+ `config.yaml`、`am.mvn`、`tokens.json`、BPE 模型；用 `scripts/download_asr_models.py` 下载 / 校验。
- 返回：`text`（去标签）、`raw_text`（原始 `<|…|>` 标签）、`rich_text`（官方后处理，可能带 emoji）、`language`、`emotion`、`event`、`duration`、`elapsed_ms`、`run_id`。
- 支持 wav / mp3 / webm / ogg / m4a / mp4；非 wav 先用 MoviePy 自带的 imageio-ffmpeg 转成 16 kHz 单声道。单次默认不超过 60 秒（`PBSC_ASR_MAX_SECONDS`）。
- 本机 CPU 实测：首次请求约 2–3 秒（含模型加载），之后 4–6 秒中文音频约 0.2 秒。
- 结果直接用于语音提问：`POST /api/v1/qa/ask` 上传 `audio` 时先本地识别，再检索和回答。识别准确率受口音、噪声和量化模型影响，需人工抽查。
- 本地兼容性补丁：`sentencepiece` 在 Windows 上不能直接加载中文路径，`third_party/SenseVoice/funasr_onnx/utils/sentencepiece_tokenizer.py` 已改为读字节加载（详见 `third_party/SenseVoice/SOURCE.md`）。
- 如需从原始 PyTorch 权重重新导出 ONNX，用单独的临时环境安装 `requirements-export.txt`，不要装进运行环境的 `.venv`（会拉 torch/funasr 并固定 numpy 版本）。

### VLM 内容理解（`agents/vlm_agent.py`、`agents/vlm_client.py`）
入口：`POST /api/v1/books/<book_id>/vlm`，可选 `page_no`、`force`；或命令行 `python scripts/generate_book.py --book <id> --steps vlm`。上传时设置 `PBSC_VLM_AUTO=1`（或表单字段 `vlm=1`）会自动提交整本 VLM 任务。

- 只要求同学 VLM 已经具备的能力：**页码、画面描述、对象名称 + bbox**；`contours`、`plot_events`、`confidence` 可选。
- 支持两种调用协议（`PBSC_VLM_PROTOCOL`）：
  - `openai_chat`：OpenAI 兼容 `/chat/completions`，图片以 data URI 放进 `image_url`；与赛题参考代码 `赛题内容/参考代码/gemini_analyze.py` 的调用方式一致。
  - `custom_json`：POST `{image, prompt, system, page_no, image_size, model}`，返回 JSON 或 `{"result": ...}`。
- 兼容参考代码的返回格式：`{"名称<English>": [x1,y1,x2,y2], ...}` 会自动转成 `objects` 列表；也支持标准的 `objects` 数组。
- 坐标：发给 VLM 前会把图缩到 `PBSC_VLM_MAX_IMAGE_SIDE`；模型返回的 bbox 会自动换算回**原图像素坐标**。`PBSC_VLM_BBOX_FORMAT` 支持 `xyxy`（像素，默认）、`xywh`（像素）、`xyxy_1000`（0–1000 相对坐标，参考代码的 `denormalize_coordinates` 就是这个约定）、`xyxy_normalized`（0–1）。
- 环境变量可直接沿用参考代码的 `IMAGE_ANALYSIS_URL` / `IMAGE_API_KEY` / `IMAGE_MODEL`，也可用 `VLM_API_URL` / `VLM_API_KEY` / `VLM_MODEL`。
- 校验：页码不一致直接失败；无效/越界/零面积 bbox 丢弃并写 `warnings`；没有对象时写空数组并告警。**没有真实 contours 就只写 bbox，阅读页显示矩形，不伪造轮廓。**
- 写回：`scene_summary`、`objects`、可选的 `plot_events`，以及 `vlm_meta`（run_id、模型、协议、图片哈希、对象数、警告、耗时）。图片哈希没变时默认复用，`force` 才重跑。
- 未配置 `VLM_API_URL` 时返回 503 `VLM_UNAVAILABLE`，不会生成假对象。
- 密钥只放 `.env` / 环境变量，不要把 Key 发到聊天或文档。

### 本地大模型与有依据问答（`agents/qa_agent.py`、`configs/prompts/qa_v1.txt`）
入口：`POST /api/v1/qa/ask`。文字用 JSON/表单字段 `question`；语音用 multipart 字段 `audio`（先走本地 SenseVoice）。必带 `book_id`、`page_no`，看视频时带 `play_time`，可带 `session_id`。

- 推理服务：`third_party/llama.cpp/` 的 `llama-server`（MIT，Windows CUDA 预编译）+ `data/models/qwen3/Qwen3-4B-Instruct-2507-Q4_K_M.gguf`（Apache-2.0，约 2.33 GB，用 `scripts/download_llm_models.py` 下载）。
- 启动：`powershell -ExecutionPolicy Bypass -File scripts\start_llm.ps1`，默认监听 `127.0.0.1:8080`，上下文 8192，`-ngl 99`、Flash Attention 和 `ubatch 1024`，自动挑 NVIDIA 显卡（`-Device Vulkan1` 可手动指定）；没有显卡时加 `-Cpu`。
- 预热：启动后跑一次 `.venv\Scripts\python scripts\warmup_llm.py`。Vulkan 后端第一次处理大 prompt 时会编译管线，冷启动首问可能 10–20 秒；预热后正常问答 1–2 秒。本机实测：显存约 3.6 GB，生成约 65 tokens/s，3 页绘本问答端到端 1.2–1.6 秒。
- 接入：`.env` 里 `SIMPLE_STORY_WRITER_URL=http://127.0.0.1:8080/v1/chat/completions`、`SIMPLE_STORY_WRITER_MODEL=qwen3-4b-instruct-2507`，Key 留空。旁白生成和问答共用这一个地址。
- 检索：每页的原文（OCR blocks）、旁白、画面描述、情节、物体说明切成小段，用中文字符二元组 + IDF 打分，选 `PBSC_QA_TOP_K`（默认 4）页；每类内容有配额，跨页重复的物体说明会去重。**是词面匹配，不是向量检索**；找不到任何词面依据时只把当前页和相邻页给模型，让它回答“书里没有讲到”。
- 回答：模型只输出 JSON（`answer`/`grounded`/`evidence`/`confidence`）。`evidence[].quote` 必须能在该页内容里逐字找到；找不到时用最接近的原文句替换，重合度不足 0.6 就直接丢弃。**`grounded` 由校验后的依据决定，模型自称不算数**；没有有效依据时统一回答“这本书里没有讲到哦。”。
- 配音：`PBSC_QA_TTS=1` 且 CosyVoice 已配置时，回答会合成音频放到 `data/tts/qa_*.wav`，`answer_audio_url` 指向 `/api/v1/tts-audio/`；合成失败或未配置时为 `null`，不返回占位音。
- 历史：每一轮自动写入 `data/history/<session_id>.jsonl`，`GET /api/v1/history?session_id=` 读取；问题录音存 `data/qa/`，用 `/api/v1/qa-audio/<文件名>` 访问。
- 局限：没有视频关键帧检索（视频依据只能定位到页对应的片段）；回答质量依赖 OCR/VLM 写回的内容是否准确；4B 模型在长绘本、多跳问题上仍可能答偏，需要题库评测。

### 语音合成（`agents/cosyvoice_client.py`、`POST /api/v1/tts`）
入口：`POST /api/v1/tts`（任意文字，回答朗读用）或 `POST /api/v1/generate/audio`（按书/页生成旁白配音）。`/tts` 返回 `audio_url`、时长和 `is_placeholder`；`/generate/audio` 是异步任务，把结果写回分页数据的 `narration_audio`。

- `PBSC_TTS_PROVIDER=cosyvoice` 时使用阿里云百炼 CosyVoice WebSocket：`run-task` → `task-started` → `continue-task` → `finish-task`，二进制音频帧拼接后保存。
- 默认 `COSYVOICE_MODEL=cosyvoice-v3-plus`、`COSYVOICE_VOICE=longanyang`、`COSYVOICE_FORMAT=wav`、`COSYVOICE_SAMPLE_RATE=22050`；Key 复用 `DASHSCOPE_API_KEY`，也可单独设 `COSYVOICE_API_KEY`。
- 音频保存在 `data/tts/`，按“文字 + 音色 + provider + model”缓存；`force: true` 才重新调用。**流式 WAV 的 data 长度会按实际字节数修正**，避免时长算成几万秒。
- 未配置真实服务时和参考 TTS 一样生成占位音频，`is_placeholder=true`，不会冒充真实配音。
- 页面旁白配音（视频链路）复用同一个 TTS 客户端；`COSYVOICE_VOICE` 或请求里的 `voice` 决定音色。
### 音色复刻与选择（`agents/cosyvoice_voice.py`）
CosyVoice 的声音复刻通过官方 DashScope SDK 的 `client.audio.voices.*` 完成，本地参考音频以 Base64 Data URI 上传，不需要公网地址。

- `POST /api/v1/voices/cosyvoice`：multipart `audio`（WAV/MP3/M4A，5–60 秒，≤10 MB），可选 `prefix`（最多 10 字符）、`target_model`、`language_hints`。返回 `voice_id`，初始状态 `DEPLOYING`，审核通过后 `OK`。
- `GET /api/v1/voices/cosyvoice` 列表；`GET/DELETE /api/v1/voices/cosyvoice/<voice_id>` 详情/删除；`PUT /api/v1/voices/cosyvoice/<voice_id>` 用新参考音频替换（保留 voice_id）。
- `POST /api/v1/voices/cosyvoice/selection` 保存选中音色到 `data/voice_selection.json`；之后 `/tts` 和 `/generate/audio` 没显式传 `voice` 时默认用它。`GET .../selection` 读取。
- 复刻音色绑定创建时的 `target_model`，不能跨模型使用；`COSYVOICE_MODEL` 与 `target_model` 要保持一致。
- 密钥只放 `.env`；接口只返回 `voice_id`/状态，不回显 Key。现有“小熊”面板仍接的是可选 ElevenLabs 服务；CosyVoice 的列表/上传/选择 UI 是下一步。

### 任务队列（`server/task_queue.py`）
旁白、视频和 OCR 都是异步任务。状态每次变化都写到 `logs/tasks/<task_id>.json`，服务重启后仍能查到历史任务；重启时没跑完的任务标记为失败（`INTERRUPTED`）。相同目标的任务未结束时重复提交会返回同一个任务。取消：排队中的直接取消，执行中的在当前页处理完后停止。

### 异常与重试（`server/errors.py`、`server/retry.py`）
所有错误都转成统一外壳和稳定的错误码。未预料的异常只返回 `INTERNAL_ERROR`，不向调用方暴露内部细节，详情在服务端日志里按 `run_id` 查。外部服务调用失败时，只对“再试可能成功”的情况重试（超时、连接失败、429、5xx），默认最多 3 次，间隔按 1 秒、2 秒、4 秒递增并加随机抖动；4xx 和返回格式错误不重试。

### 运行记录（`server/run_logger.py`）
见 [logs/README.md](../logs/README.md)。每次生成一个 JSON 文件，记录 run_id、时间、输入、提示词版本及文件哈希、模型及参数、输出文件路径及哈希、耗时、费用、错误、上级 run_id、代码提交号。密钥字段写入前会被遮蔽。

## 4. 旁白生成（步骤 4）

入口：`POST /api/v1/generate/narration`，或命令行 `python scripts/generate_book.py --book <book_id> --steps narration`。

做法是“讲述原书”，不是创作：

1. 输入取自分页数据：本页原文、画面摘要、情节、人物设定表、上一页旁白。
2. 提示词在 `configs/prompts/narration_v1.txt`。文件名就是版本号；要改提示词请另存为 `narration_v2.txt` 并把 `agents/story_agent.py` 里的 `PROMPT_NAME` 指过去，不要直接改旧文件，这样旧结果仍可追溯。
3. 调用方式沿用参考代码的故事模块（OpenAI 兼容的 chat/completions，地址、密钥、模型都来自环境变量，可以接 DeepSeek、Qwen 等，代码不绑定厂商），温度 0.3。
4. 生成后做程序化检查：

| 检查 | 不通过时 |
|---|---|
| 旁白为空 | 重试 |
| 超过长度上限（绝对上限 220 字，且不超过原文长度的 2.5 倍加 20 字） | 重试 |
| 明显短于原文（不到一半） | 重试 |
| 夹带标记、括号说明、音效标签 | 重试 |
| 原文里出现的人物没有被讲到 | 重试 |
| 内容大多找不到原文依据（依据度低于 0.15） | 重试 |
| 依据度偏低（低于 0.30）、原文保留偏少、把规范称呼换成了别名、出现“小朋友你知道吗”这类互动 | 多试一次，仍有问题则采用但标记“需人工复核” |

“依据度”是旁白里相邻两个字的组合有多大比例能在本页原文、画面摘要、情节、人物和物体名称里找到，是一个粗略的防编造指标，不能代替人工复核。

5. 重试时会把上一次的输出和没通过的原因一起发给模型。最多 3 次仍不通过，或大模型调用失败、预算用完，就**退回直接朗读原文**，保证不会把编造的内容讲给孩子。
6. 写回 `narration` 和 `narration_meta`，并把 `safety_check.status` 重置为 `pending_review`。

## 5. 视频生成（步骤 5）

入口：`POST /api/v1/generate/video`，或命令行 `python scripts/generate_book.py --book <book_id> --steps video`。

每页的流程：

1. **提示词**：`configs/prompts/video_v1.txt` 模板，填入本页画面摘要、情节、本页人物的外观设定、上一页和下一页的画面摘要，并固定要求“画风、配色、人物造型不变，不新增人物和文字，镜头缓慢”。
2. **配音**：旁白 → TTS → `audio/page_NNN.wav`。
3. **图生视频**：原绘本页插图作为首帧 → `video/raw/page_NNN.mp4`。可选两种服务：
   - `PBSC_I2V_PROVIDER=gateway`（默认）：沿用参考代码的网关，首帧默认以 base64 放进请求。
   - `PBSC_I2V_PROVIDER=dashscope`：阿里云百炼（DashScope），用官方 SDK 提交 `wan3.0-video` 等模型；SDK 会先把本地页图上传到临时 OSS，不需要本机有公网地址。
4. **合成**（MoviePy）：片段等比缩放居中到 1280×720 画布，不裁剪；页时长取“旁白时长 + 0.8 秒”和 3 秒中较大的；片段不够长时先放慢（最多到 1.25 倍时长），再用最后一帧定格补足；叠加字幕（按句切分，按字数分配时间）→ `video/clips/<clip_id>.mp4`。
5. 全部页完成后**拼接**成 `video/book.mp4`，页间 0.5 秒交叉淡入。每页的 `time_range` 取“本页开始到下一页开始”，相邻页首尾相接。
6. **写回**每页的 `video_clip_id`、`time_range`、`video_prompt`、`narration_audio`、`video_meta`，书级的 `video`，并导出 `video/clip_index.json` 给 B 建检索。

带 `page_no` 提交时只做到第 4 步，生成这一页的成片，不动整本视频；这时书级 `video.stale` 会被置为 `true`，表示整本需要重新拼接。

### 图生视频服务选择（阿里云百炼 / 旧网关）

`.env` 里设置 `PBSC_I2V_PROVIDER=dashscope` 后走百炼：

```dotenv
PBSC_I2V_PROVIDER=dashscope
DASHSCOPE_API_KEY=sk-...          # 只放 .env 或系统环境变量，不要写进代码/前端/聊天记录
# DASHSCOPE_WORKSPACE_ID=         # 调用地址形如 ws-xxxx.cn-beijing.maas.aliyuncs.com 时填写
# PBSC_DASHSCOPE_BASE_URL=        # 可选：workspace 专属的 /api/v1 地址；一般填 Workspace ID 即可
# PBSC_DASHSCOPE_MODEL=wan3.0-video-prime
# PBSC_DASHSCOPE_RESOLUTION=1080P  # 480P/720P/1080P
# PBSC_DASHSCOPE_MEDIA_PROTOCOL=auto   # auto/media/image_url；wan3、wan2.7-i2v 默认 media
# PBSC_DASHSCOPE_RATIO=adaptive
# PBSC_DASHSCOPE_TIMEOUT=300
# PBSC_DASHSCOPE_POLL_INTERVAL=1  # 轮询间隔，越小越快发现完成
# PBSC_DASHSCOPE_MAX_INTERVAL=3   # 轮询退避上限
# 要 1080P 成片，最终合成画布也要设为 1080P：
PBSC_VIDEO_WIDTH=1920
PBSC_VIDEO_HEIGHT=1080
```

- **密钥安全**：代码只从环境变量读取；`.env` 已被 `.gitignore` 忽略；`GET /api/v1/health` 只显示“已配置/未配置”，运行记录会遮蔽密钥字段；前端不会拿到密钥。建议在百炼控制台单独建一个 Key，并设置预算。也可以运行 `.venv\Scripts\python scripts\configure_dashscope.py`，它用隐藏输入读取 Key 后写入 `.env`，Key 不会出现在屏幕、命令历史或聊天里。
- **1080P**：`PBSC_DASHSCOPE_RESOLUTION=1080P` 只控制百炼生成的原始片段；项目最后会用 MoviePy 合成整本视频，如果 `PBSC_VIDEO_WIDTH/HEIGHT` 仍是 1280×720，成片还是 720P。要交付 1080P，必须同时设成 `1920×1080`。1080P 的合成、编码更慢、占内存更多，建议先只跑一页测时间。
- **首帧协议**：`auto` 时 `wan3*`、`wan2.7-i2v` 用 `media=[{"type":"first_frame","url":本地图片}]`，旧模型用 `image_url`；SDK 会自动上传本地图片。若 API 报协议不匹配，可用 `PBSC_DASHSCOPE_MEDIA_PROTOCOL` 强制选择。
- **认证检查**：`python scripts/check_dashscope.py` 只调用任务列表接口验证 Key/区域/Workspace，不生成视频、不产生生成费用。
- **费用与降级**：每次生成都记入 `logs/cost_ledger.jsonl`，预算默认每天 30 次（`configs/pricing.json`）。未配置 Key、调用失败或超时都会改用本地推近片段，原因写在 `video_meta.fallback_reason`，不会伪造 AI 视频。
- **最小验证**：先只生成一页（`?page_no=1` 或网页单页成片），确认真实视频、耗时和费用后再跑整本。

### 演示时长与预生成（比赛建议）

1080P 视频生成是异步离线任务，单段 5 秒实测约 60–70 秒（百炼排队 + 生成 + 下载），**不适合现场临时跑完整本**。比赛建议：

1. **预生成大部分内容**：赛前用 `python scripts/generate_book.py --book <id> --steps video` 生成并缓存；生成结果和 run_id 留在 `logs/`，答辩时如实说明哪些是预生成。
2. **现场只留一页实时生成**：按分工说明的“预生成与现场生成”口径，至少保留一页从上传到出视频的完整链路。进入演示后先提交这一页，让它后台跑，继续讲别的功能；60–70 秒后回来展示结果。
3. **不要串行现场跑整本**：3 页串行约 3–4 分钟，容易超时。需要整本时提前生成，或按下面的并行/降分辨率方案。
4. **降低现场等待**：`PBSC_DASHSCOPE_POLL_INTERVAL=1`、`PBSC_DASHSCOPE_MAX_INTERVAL=3` 把“完成后才发现”的轮询延迟压到几秒；已设置。
5. **分辨率分层**：如果比赛允许，现场可用 720P 快速版演示交互，最终提交的 1080P 视频预先生成；如果必须现场 1080P，就只跑一页并提前开始。
6. **缓存优先**：同一页输入不变时直接复用 `video/raw/` 和 `video/clips/`，第二次不再调用百炼，播放是即时的。

### 缓存与费用控制

- 配音、图生视频片段、单页成片都按输入内容做缓存。输入没变（同一张图、同一段提示词、同一个模型和参数）就直接复用，不再调用收费服务。只改旁白时，图生视频片段不会重做。
- `force: true`（命令行 `--force`）才会忽略缓存重新调用。
- 每次调用都在 `logs/cost_ledger.jsonl` 记一行：时间、run_id、服务、模型、用量（视频秒数、token、字符数）、金额、绘本和页码。汇总看 `GET /api/v1/costs` 或 `python scripts/generate_book.py --costs`。
- 单价和预算在 `configs/pricing.json`。**单价目前都是空的，需要按服务商的价目表填写**；没填时台账只记用量，金额为空，不会编造价格。
- 预算默认是图生视频每天 30 次、大模型和 TTS 各每天 500 次，可改。达到上限后不再调用对应的收费服务，改用降级方案并写明原因。
- 图生视频调用失败（重试后仍失败）也会改用降级片段，原因写在 `video_meta.fallback_reason`。降级片段不占缓存，下次运行会重新尝试真实服务。

### 字幕字体
自动查找顺序：Noto Sans SC / 思源黑体 / 文泉驿（开源许可）→ 系统自带的微软雅黑、黑体等。用了哪种字体会写进 `video_meta.subtitle_font`，请据此在素材来源清单里披露。Linux 服务器上需要先安装一种中文字体（例如 `fonts-noto-cjk`），或用 `PBSC_SUBTITLE_FONT` 指定字体文件；找不到字体时会跳过字幕并在运行记录里注明。

### 速度参考
本机（无独立 GPU 参与，1280×720，24 帧）用降级方案合成 3 页 28 秒的整本视频约 22 秒，全部是本地编码时间。接入真实图生视频后，总时间主要取决于外部服务的排队和生成时间，目前没有实测数据。

## 6. 命令行脚本

| 命令 | 作用 |
|---|---|
| `python -m server` | 启动服务 |
| `python scripts/download_ocr_models.py` | 下载 / 校验本地 OCR 模型 |
| `python scripts/download_asr_models.py` | 下载 / 校验本地 SenseVoice 模型 |
| `python scripts/transcribe_audio.py ask.wav` | 不启动服务，识别一个音频文件 |
| `python scripts/configure_dashscope.py` | 隐藏输入 Key，写入 `.env`（不回显、不进历史） |
| `python scripts/check_dashscope.py` | 检查百炼 Key/区域/Workspace 认证（不生成视频） |
| `python scripts/generate_book.py --book demo_book --steps ocr` | 不启动服务，只跑本地 OCR |
| `python scripts/generate_book.py --book demo_book --steps vlm --page 1` | 不启动服务，只对第 1 页跑 VLM |
| `python scripts/generate_book.py --book demo_book --steps audio --page 1` | 不启动服务，只生成第 1 页配音 |
| `python scripts/generate_book.py --book demo_book` | 不启动服务，直接跑旁白和视频 |
| `python scripts/generate_book.py --costs` | 查看费用汇总 |
| `python scripts/make_sample_book.py --video` | 重新生成示例绘本和示例视频 |
| `python scripts/smoke_reference_server.py` | 逐接口测试参考后端，刷新实测结果表 |
| `python scripts/run_reference_server.py` | 启动参考后端（修正了地址前缀和编码问题） |
| `python -m pytest` | 运行全部测试（111 项，约 1 分钟；若示例视频被替换成 Git LFS 指针，会有 1 项媒体检查失败） |
