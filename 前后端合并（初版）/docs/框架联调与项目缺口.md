# 前后端统一框架与项目缺口

本轮交付以五人分工说明和赛题要求为目标。框架已将小屋页面、统一业务接口、生成节点与数据存储串起来；核心智能模块尚未全部完成，不能据此宣称达到参赛门槛。

## 启动和验收入口

在项目根目录安装 `requirements.txt` 后，双击 `启动项目.bat`，或执行：

```powershell
.\.venv\Scripts\python.exe -m server
```

打开 http://127.0.0.1:8000/ 。页面和 API 由同一个 Flask 服务提供。不要同时启动 `前端/启动网站.bat`，它只提供静态文件且占用相同端口。

- 空书库首次启动时复制自制《朵朵找月亮》到 `data/books/`；已有书库不覆盖。`PBSC_INSTALL_SAMPLE=0` 可关闭。
- 兔子：后端选书、真实图片上传、旁白任务→视频任务、进度查询、停止与重试。
- 阅读页：后端页面图、翻页、单页视频切换、旁白音频、点击识物、问答提交与证据跳转入口。
- 狐狸：浏览器保存收藏 ID 和页码，打开时从后端重新读取内容；不是多用户云端书架。
- 熊熊：通过主站音色入口接入可选独立服务；未配置时禁用相关能力并显示原因。
- 猫头鹰：保留本地演示书固定题目。后端绘本暂无真实题库。
- `?mock=1` 明确切到假接口，供界面联调；不代表真实推理。

模型未配置时：旁白回退原文、视频采用本地推近效果、配音采用占位提示音，页面显示降级标识。新上传的图只有图片，OCR/VLM 尚未实现，不能自动得到真实原文与人物信息。

## 架构与模块边界

```text
浏览器：前端/index.html + app.js
  ├─ api/service.js → /api/v1 → server/api.py
  │    ├─ BookStore → data/books/<book_id>/book.json + 页图/音频/视频
  │    ├─ TaskManager → 旁白节点 → 配音/图生视频 → MoviePy 合成
  │    ├─ touch → 已有页面框/关键帧框查表
  │    └─ ASR / QA / history → 待实现，返回明确的 501
  ├─ api/voice.js → /api/voice/status、/api/voices/... → 可选音色服务
  └─ ?mock=1 → /mock/api/v1 → 固定模拟数据
配置 configs/；输入输出与提示词追溯 logs/；费用台账与预算 agents/cost.py。
```

视频无关键帧标注时返回“尚无关键帧标注”，不套用原绘本坐标。查表无结果的 VLM 兜底尚未实现。静态托管只开放页面所需资源，不开放环境配置、后端源码或音色数据库。

## 可选音色模块

额外安装 `前端/requirements.txt`，在项目根目录另开终端：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.server:create_app --factory --app-dir 前端 --host 127.0.0.1 --port 8001
```

主服务的环境变量配置 `PBSC_VOICE_SERVICE_URL=http://127.0.0.1:8001` 后重启主服务。独立服务进程使用自己的环境变量 `ELEVENLABS_API_KEY`、可选 `VOICE_ACCESS_TOKEN`；该服务不自动加载 `.env`。音频注册需要 FFmpeg 和 ffprobe 可执行文件在 PATH 中。只在服务器配置密钥。

主站转发音色注册、列表、选择和音频二进制；选择的克隆音色用于阅读时即时朗读。生成视频里的配音仍使用生成节点的 TTS，尚未将 voice_id 贯穿这条链路。转发协议用替身验证，未调用付费音色服务、未验证音色相似度。

## 建议推进顺序

1. B 先完成一本合法模拟绘本的 OCR/VLM 结构化与人工核对，全员确认分页格式。
2. A 配置真实 LLM/TTS/图生视频跑完这一本，记录生成质量、费用、失败和耗时。
3. B 完成视频索引和有依据的 QA；C 对接录音、证据跳转和多模态历史；A 接流式语音。
4. D 用题库和触控集跑基线，再据错误类型优化；E 同步补齐审核责任与素材台账。
5. 做真实平板及比赛部署环境验收，完成官方评测对接和提交材料。
