# 小熊音色模块：最小闭环

## 此版实现什么
参考音频（上传或浏览器录音）→ 后端真实解码及转码 → 外部服务注册声音 → SQLite 保存稳定音色 ID → 任意新文字合成 → 播放 → 选作阅读讲述声音。

同一音色可重复使用，不是只播放样本录音，也不是每段文字都重新克隆。当前单次上限 3000 字，后续可按段落持续合成。未实现长文自动分块、流式音频、自动缓存、失败片段重试或与视频重新对齐。

## 什么是真的，什么尚未验证
- 有真实的 ElevenLabs Instant Voice Cloning / TTS 适配器，不需要下载 GitHub 项目或本机模型。
- 未配置服务密钥时返回 503 NOT_CONFIGURED，不会生成任何假克隆音频或替换为系统朗读。
- 服务商要求 further verification 时保存为 verification_required，并禁用试听和选用，不能假报成功。此版本需要在服务商侧处理验证，验证状态同步尚未实现。
- 已通过本地后端协议测试，包括复用同一 provider_id 合成两段不同文字；测试使用明确的替身服务，不代表真实音色效果验证。
- 尚无用户服务密钥、授权人声样本，因此没有调用真实付费服务，未验证音色相似度、自然度或中文长文质量。
- 小屋的故事生成、视频、识物和问答仍是前一版演示；小熊的真实服务状态单独标记。选中后阅读页调用克隆 TTS，但尚未将音色 ID 接入真实故事视频流水线。
- 在线私有预览为静态托管，无法运行 Python 后端。可看交互、录音与音频本地试听；注册和新文字合成需要本机完整服务，或者后续另行部署后端。浏览器从静态站直接访问服务商密钥不会被采用。

## Windows 本机启动
1. 解压整个文件夹到 `D:\绘本比赛前端网站`。
2. 安装 Python 3.10+、FFmpeg（包含 ffprobe），确保 `python`/`py`、`ffmpeg` 和 `ffprobe` 可在终端运行。
3. 在项目目录终端执行：`py -m pip install -r requirements.txt`。
4. 双击 `启动音色服务.bat`。按提示输入 ElevenLabs API Key，输入不回显、不会写入文件；留空可以查看“尚未连接”状态。
5. 浏览器打开 `http://localhost:8000`，点击小熊。
6. 给音色命名，上传或录制 10—120 秒音频；建议 30—60 秒清晰单人成人语音。10—120 秒是本应用限制，不是服务商质量保证。
7. 确认授权后注册，选择保存后的声音，输入与样本不同的文字，点击生成并播放；至少再换一段文字测试音色复用。
8. 点击“选作故事讲述声音”，打开演示绘本后点击朗读，使用相同 provider_id 调用 TTS。

不要把服务商密钥发送到聊天或填到前端。若使用系统环境变量，可设置 ELEVENLABS_API_KEY 后重启；参考 .env.example，但程序不自动加载 .env。

Linux/macOS：安装依赖及 FFmpeg 后执行 `python -m backend.launch`。也可设置服务端环境变量后执行 `python -m uvicorn backend.server:create_app --factory --host 127.0.0.1 --port 8000`。

原来的“启动网站.bat”只启动静态演示，不支持音色后端。本模块必须使用“启动音色服务.bat”。

## 接口（本项目新增协议，不是赛事统一接口）
- GET /api/voice/status：configured、audio_tools、limits；检查连接，不代表服务商已验证密钥或账户额度。
- GET /api/voices：voices（id,name,status,duration,created_at）、selected_voice_id。
- POST /api/voices：multipart name、audio（真实文件）、consent=yes。返回 {voice:{id,name,status,duration}}。
- POST /api/voices/{id}/speech：JSON {text:"新文字"}；返回 audio/mpeg 二进制。不返回 Base64 JSON。
- POST /api/voices/selection：JSON {voice_id:"本地稳定 ID"}，返回 selected_voice_id、name。
- 错误统一 {error:{code,message}}。未配置 503；字段或音频错误 422；音色不存在 404；需验证 409；额度/频控 429；上游失败 502；上游超时 504。
- 上游请求 120 秒，浏览器 150 秒；注册超时不自动重试，需刷新列表并检查服务商控制台，避免重复注册收费。
- 单次音频不超过 20 MB，单次文本不超过 3000 字。用户注册样本为临时文件，转码后发送上游，随后删除；本机仅保存音色元数据。外部服务持有参考样本/音色，其保留与删除需按服务商政策管理。

## 服务配置与文档
适配文件 backend/server.py，官方协议核对日期 2026-11-11：
- https://elevenlabs.io/docs/api-reference/voices/add
- https://elevenlabs.io/docs/api-reference/text-to-speech/convert

使用 xi-api-key，在后端调用 /v1/voices/add 和 /v1/text-to-speech/{voice_id}，默认 eleven_multilingual_v2。账户必须有相关音色克隆权限及额度，可能收费；实际质量、支持范围和要求以服务商为准。

若后续采用国内服务或本地模型，只需替换 provider.enroll(name,wav) 和 provider.synthesize(provider_id,text)，保留前端协议。不需要重写小熊面板。

默认服务仅限本机，不允许任意跨域。不要把单用户 SQLite 服务直接暴露到公网。远程部署需要 HTTPS、用户鉴权与隔离、限流、上传限制和持久存储；VOICE_ACCESS_TOKEN 是本版本可选的共享访问凭证，不是完整多用户认证。

## 测试与后续验收
运行 `python -m unittest discover -s tests -v`。覆盖有效音频解码、注册和复用、持久化、未连接、需验证、无授权、无效音频、空文字、上游失败、访问保护。测试 WAV 是静音测试夹具，合成返回测试字节，不能用于证明真实声音克隆效果。

仍需用户提供有权限的服务账户与授权样本后：至少三段不同文本对比试听、重启后复用、中文数字与人名发音、音频加载/播放、录音权限和移动端布局验收。尚未完成浏览器点击与视觉验收。
