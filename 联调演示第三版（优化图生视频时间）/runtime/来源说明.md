# 第三方运行组件

- Python 3.13.17 适用于 Windows x64，使用 [Python.org 嵌入式发行包](https://www.python.org/downloads/release/python-31317/)。许可证位于 `python/LICENSE.txt`。项目路径和 Python 包路径由 `python/python313._pth` 提供。
- Python 包来自 PyPI，版本见 `requirements-lock.txt`。随包保留发行元数据及许可证文件。FFmpeg 来自 imageio-ffmpeg 0.8.1 的 Windows wheel，为 Gyan 的 9.0.2 essentials 版本。对应源代码入口和构建信息可从 [Gyan 构建发布页](https://www.gyan.dev/ffmpeg/builds/) 和 [FFmpeg 9.0.2 源码](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz) 获取。
- llama.cpp b12393 的 Windows x64 Vulkan 运行时及 MIT 许可证保存在 `third_party/llama.cpp/`。CPU 模式沿用同一运行时。
- Qwen3-4B-Instruct-2507 的 Q4_K_M GGUF 由 [Unsloth](https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF) 提供，轻量 Qwen3-0.6B Q8_0 GGUF 由 [Qwen](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF) 提供，适用 Apache-2.0，许可文本位于 `third_party/Qwen3/LICENSE`。
- OCR 模型来源和授权见 `third_party/RapidOCR/MODEL_LICENSES.md`。语音识别模型来源见 `third_party/SenseVoice/SOURCE.md` 与 `data/models/sensevoice/MODEL_CARD.md`。
