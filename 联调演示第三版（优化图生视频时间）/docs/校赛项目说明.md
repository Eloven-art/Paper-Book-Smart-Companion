# 纸书智伴 · 校赛项目说明

## 项目目标

用户可以上传一份自制绘本 PDF，在网页阅读，通过语音询问故事内容并回到原书依据页。后台可生成旁白、配音和视频，阅读者可按视频时间定位内容并与标注对象互动。

## 系统流程

1. Flask 接收原 PDF，逐页渲染，读取可用文字层，扫描页交由本地 OCR。失败页暂停，用户可跳过或重传。
2. 绘本入库后可立即阅读。独立后台任务串联画面解析、旁白、配音、视频合成。支持查看、取消和继续。
3. ASR 转写问题。问答结合原文、画面和已有视频索引检索依据，经本地大模型生成并校验引用。画面与视频依据分别保留页码和时间点。
4. 视频按帧建立对象框和描述，邻近帧跟踪短距离位移。向量服务配置后执行语义匹配。播放前按人工签核状态控制成片与旁白访问。
5. 可选的 CosyVoice 功能在明确授权后注册成人音色。云端视频、配音与画面服务按已配置档位记录用量，支持本地推近等降级方式。

## 测试与限制

- 评测使用自制《朵朵找月亮》和 30 道自编问题，包括原文、跨页、画面及书外拒答。语音样本由普通话合成生成。逐题报告保留响应、转写、依据和耗时。关键词初判需人工复核。
- 历史报告与第三版结果分开保存。答辩展示仍需补测现场说话人、设备和网络。视频按时间检索及触控由最终签核的视频和索引决定。
- 参赛团队需记录自制素材、开源模型和第三方服务的来源与授权。已运行的模型和服务见校赛验收与运行单。学校提交要求及真实复核人员信息在定稿时填写。
