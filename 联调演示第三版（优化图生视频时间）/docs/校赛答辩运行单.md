# 第三版校赛答辩运行单

## 配置与前夜彩排

- 用「一键配置.bat」准备依赖和 Qwen3 4B、本地 OCR、ASR，再用「一键启动.bat」启动。第三版答辩以正式模式为主；预览模式适合展示备份。
- 使用团队自制绘本 PDF、成人录音或合成测试语音。先走一遍上传、自动生成、阅读、问答与人工签核。账号授权、受限数据和个人录音均按团队规则保管。
- 自动生成默认开启。入库后在阅读页查看后台任务、取消或继续。画面解析失败会列出页码，已入库的页仍可读。画面理解、配音和云端视频依赖各自服务配置。
- 上台前由团队指定真实复核人，使用校赛验收文档的命令，对整本成片和音轨实际复核并签核。不要代签。重新生成后核对复核状态。
- 核对现场 CosyVoice 账户、模型、区域和可用额度。由本人或获授权成人在现场确认后录音，注册时观察部署状态，转为就绪后试听一句并选用。彩排计时从注册提交到可试听。备好已审核音轨、人工确认的备用视频与截图。
- 对 VLM、向量服务、音色注册填写对应模型的服务商单价，再进行云端彩排。没有可确认单价的模型受总预算保护时会被拒绝。视频 20 元、TTS 5 元、合计 25 元是项目配置值；按实际计费档位核对后再用。
- 单机内对在途图生视频、合成、VLM、向量请求及音色注册预留费用和次数。网络超时的供应商计费、多个同时运行的服务实例以及外部大模型的词元账单以供应商账单为准。校赛主线使用本地大模型。彩排用 PBSC_VIDEO_WORKERS=2 对比单页并发，从台账记录模型、分辨率、降级、耗时和账单，选实际稳定档位。

## 视频索引与演示

1. 对正式成片运行 python scripts/index_video.py demo_book --anchor-delay 3。发生 429 或其他可恢复失败后用同一参数继续；完成页与同参数下已持久化的帧会复用。
2. 配置 PBSC_EMBEDDINGS_URL、PBSC_EMBEDDINGS_MODEL、PBSC_EMBEDDINGS_KEY 和该模型预算单价。可用向量建立后，分别核对查询的帧时间、跳转、触控和真实可播放原片。
3. 预先选两个只靠视频画面才可回答的问题，人工登记参考答复、帧时间与对象框。展示时说明成片是否赛前生成，按实际结果区分云端生成和本地推近。

## 展示顺序

- 先上传自制 PDF，展示全书入库、翻页、后台任务以及无须等待生成即可继续阅读。
- 使用真实麦克风提问，核对本机 ASR 转写和可跳转的确切依据。
- 播放已签核成片，跳到有视频依据的时间点并点击目标物体。
- 现场注册获授权成人的短录音，观察部署、试听和选用。注册等待期间展示评测摘要与失败样例。
- 展示复核、素材授权、离线备用录像及下一阶段差距。现场断网时明确说明使用的是备用素材。

## 提交检查

- 将最终自测报告、项目说明、版本号、提示词和模型来源、第三方服务和素材授权一并登记。
- 补录演示视频，保存现场机器的关键截图、实际播放结果及签核记录。限制文件交付和校内答辩时长按校方通知执行。
- 历史报告和截图来自 PDF 修复版。第三版实际效果以本版自测与现场彩排为准。
