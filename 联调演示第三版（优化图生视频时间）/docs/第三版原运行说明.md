# 纸书智伴 · 校赛演示版首次运行

1. 完整解压，进入「前后端合并（初版）」。Windows 64 位需安装 Python 3.10–3.13。
2. 双击「一键配置.bat」，安装依赖并下载 OCR、ASR、标准 Qwen3 模型。失败后可重跑，保留已校验的文件。
3. 双击「一键启动.bat」。脚本启动本地模型、等待就绪、自动预热，再启动 Flask。打开终端给出的本机 URL。
4. 8080 被旧模型服务占用时先退出旧服务。正常退出用 Ctrl+C。

- 仅用 CPU 时执行「一键启动.bat -Cpu」。轻量模型用「一键配置.bat --lite」安装，再执行「一键启动.bat -Lite」。
- 真实阅读页已接录音和 ASR。用成人测试音频验证，核对转写后发送。
- 小熊面板使用 CosyVoice，需配置 CosyVoice 凭据与 TTS provider。仅上传获授权的成人声音。
- 已装网页依赖、尚无模型时，执行「一键启动.bat -Preview」并打开 /?preview=1。该入口展示浏览器书架、导入和预置样例。
- 一键启动启用儿童复核。新生成旁白和音视频的筛查与签核方法见 docs/校赛验收.md。
- 旧包凭据问题仍待处理，避免转发含真实 Key 的包。

## 正式页面上传整本 PDF

在「大人准备绘本」选择一本 PDF，点击「保存到书架」。后台先生成页图，逐页读取文字层，必要时用本机 RapidOCR。页面统一显示「正在上传」。遇到单页失败可跳过或重传；上传失败或取消的记录可在「垃圾桶」查看。

## 第三版校赛模式

正常启动会开启儿童审核。正式模式导入 PDF 后默认排队生成素材，阅读页可查询、取消或继续；入库的绘本可以先阅读原文。云端素材生成及音色注册需校对服务密钥、模型和单价。现场演示、整本视频帧索引和预算配置请看前后端合并（初版）/docs/校赛答辩运行单.md。
