# 纸书智伴 · 第三版开发基线

适用于 Windows 10/11 64 位（Intel 或 AMD）。从 GitHub 下载这一版，完整解压到有写权限的文件夹，进入「联调演示第三版（优化图生视频时间）」并双击「一键启动.bat」。首次启动会联网下载缺失的运行文件，校验安装后自动打开网页。使用期间保持终端开启，结束时按 Ctrl+C。

Python 与运行依赖、FFmpeg、llama.cpp、Qwen3、RapidOCR、SenseVoice 和示例音视频均随版本提供。首次启动建议预留至少 9 GB 磁盘空间，下载中断后可以重新双击续传。文件就绪后可离线运行。普通 CPU 可以运行，首次加载和问答速度取决于机器配置。标准模式建议有 16 GB 内存。

| 启动方式 | 用途 |
| --- | --- |
| 双击「一键启动.bat」 | 标准 Qwen3 4B 模型，自动检测 NVIDIA，可用 CPU 回退 |
| `.\一键启动.bat -Cpu` | 强制用 CPU 运行标准模型 |
| `.\一键启动.bat -Lite` | CPU 运行已随包附带的 Qwen3 0.6B，适合内存较小的机器 |
| `.\一键启动.bat -Preview` | 跳过问答模型，查看网页和示例素材，打开 `/?preview=1` |

带参数的命令在项目文件夹的 PowerShell 中运行。如遇端口占用，退出之前启动的项目后重试。若 Windows 提示缺少 `MSVCP140.dll` 或 Visual C++ 运行组件，可安装微软的 [x64 Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

## 可以直接体验的功能

- 打开自制示例绘本，阅读原文、播放预置音视频，用本地模型提问。
- 在「大人准备绘本」选择整本 PDF 上传。扫描页用本地 OCR，单页失败可跳过或重传。
- 使用本地 SenseVoice 进行录音转写。未配置云端视频服务时，生成的视频采用标注清楚的本地推近片段。
- 新生成的音视频遵循儿童审核流程。复核和签核见 [校赛验收](docs/校赛验收.md)。

真实云端图生视频、CosyVoice 配音和音色克隆、云端 VLM 和向量检索需要联网和接收者自己的服务配置。在本机把 `.env.example` 复制为 `.env`，按模板填写，重启即可。项目默认走本地问答和本地降级流程。

## 继续开发

启动器读取随版本提交的资源清单，从 GitHub 自动下载缺失的 Windows 运行包和 OCR/ASR 模型包，并校验 SHA-256。问答模型按需从发布源下载，同样校验 SHA-256。开发者使用 Git LFS 克隆时也可沿用已还原的运行文件和 Qwen3 4B 分卷。

分享本目录时请确认 Git LFS 文件已经下载到本机，并完整打包目录。已有本地测试数据或密钥配置请在打包前移出。

- `前端/`、`server/`、`agents/`、`configs/` 分别保存界面、API、处理链和配置。图生视频优化位于 `agents/video_agent.py` 与 `agents/video_compose.py`。
- 运行后端测试使用 `.\runtime\python\python.exe -B -X utf8 -m pytest`。前端测试使用 `node --test tests/test_frontend.mjs`，需要另装 Node.js。
- 「一键配置.bat」供按源码重建独立虚拟环境。打包时使用的 Python 依赖版本见 [运行环境清单](runtime/requirements-lock.txt)，第三方组件来源见 [第三方组件说明](runtime/来源说明.md)。
- 开始使用后，本机上传的绘本和记录存放在 `data/` 下，模型配置在本机 `.env`。
